# mattduerr.github.io

Matt's GitHub Pages site, served at <https://mattduerr.github.io> from `main`.

It exists so the Google Cloud project "Home Assistant" (Google Calendar
integration for HA) can be published: Google requires a homepage and a
privacy policy on an authorized domain before an external app leaves
Testing mode.

| File | URL | Used in Google Auth Platform → Branding as |
| --- | --- | --- |
| `index.html` | `https://mattduerr.github.io` | Application home page |
| `privacy.html` | `https://mattduerr.github.io/privacy.html` | Application privacy policy link |

Authorized domain: `mattduerr.github.io`.
